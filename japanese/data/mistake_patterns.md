# Mistake Patterns

Use this file to track repeated corrections. Keep examples short and reusable.

## Pattern 1: Time expression placement

Less natural:

```text
北海道の帯広、8月旅行しました。
```

More natural:

```text
8月に北海道の帯広へ旅行しました。
```

Why:

Put time expressions like 8月に before the place and action.

## Pattern 2: Polite past verb form

Question:

```text
食べた？食べました？
```

Note:

```text
食べた = casual past
食べました = polite past
```

Example:

```text
豚丼を食べました。
```

Casual version:

```text
豚丼を食べた。
```
