# Daily Start Prompt

Copy this into ChatGPT voice at the beginning of a session.

```text
Today is Day __ of my 30-day Japanese daily conversation plan.

Please run a 15-minute Japanese conversation practice session.

Use this structure:

1. Warm-up conversation
2. Review previous vocabulary
3. Main conversation topic
4. Short Japanese reading aloud text
5. Corrections and natural phrases
6. Homework

Today's topic:
___

Today's conversation goal:
___

Useful phrases I want to practice:
___

Yesterday's log:
___

Recent vocabulary:
___

Recent mistakes:
___

My interests:
gaming, anime, music, movies, travel, Japanese food, desserts, Hokkaido, Obihiro, soft cream

Reading aloud rule:
Write hiragana in parentheses after kanji words, like 日本語（にほんご） and 旅行（りょこう）.

Teacher style:
- casual and natural
- not textbook-like
- ask one question at a time
- let me speak first
- correct me gently after I answer
- explain in English only when needed
```
