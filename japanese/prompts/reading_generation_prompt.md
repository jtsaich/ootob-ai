# Reading Generation Prompt

Use this when ChatGPT has web search or current information available.

```text
Find a current Japanese topic related to one of my interests:

- games
- anime
- music
- movies
- travel
- Japanese food
- desserts

Then create a short Japanese reading aloud passage for me.

Rules:

1. Do not copy a long article directly.
2. Summarize the information in simple Japanese.
3. Make the reading 3-6 sentences.
4. Use natural but beginner-friendly Japanese.
5. Write hiragana in parentheses after kanji words, like 日本語（にほんご） and 旅行（りょこう）.
6. Include vocabulary with English meanings.
7. Include 2 follow-up conversation questions.
8. Include one short writing homework assignment.

Output format:

# Reading Aloud

# Vocabulary

# Conversation Questions

# Homework
```
