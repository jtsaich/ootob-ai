FAQ

常見問題

一定要用 Messaging API 嗎？

不用。固定 FAQ、營業時間與表單連結，優先用 LINE 內建功能。只有即時資料、身分、狀態或外部串接才需要 API。

建置後一定有月費嗎？

基礎方案不綁維護月費。Messaging API 若需要主機、資料庫或第三方服務，會在報價中分開列出。

LINE 官方方案費包含在報價內嗎？

不包含。LINE 官方帳號方案與訊息費由帳號持有人依官方價格及實際用量支付，不會混進開發費。

帳號會建在你們名下嗎？

不會。正式 OA、LINE Business ID 與 Provider 都由客戶持有，我們只用受邀權限建置。

可以先做基礎版，以後再串系統嗎？

可以。先把 Profile、Rich Menu 與固定內容整理好，之後有明確資料流程再加 Messaging API，通常風險更低。

開始前要準備什麼？

品牌名稱、Logo、聯絡資料、Rich Menu 架構、FAQ 文案、要連出去的網址，以及一位能決定內容與驗收的人。
