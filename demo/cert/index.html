舊版 Linux 證書系統資料匯入

階段作業產出
1. 匯出從舊系統匯出 CSV 或 SQL dump；附件圖片與簽名檔整包複製原始資料包、校驗碼
2. 欄位對應舊欄位 → 新範本欄位對照表；缺少的欄位給預設值或標「舊資料」對照表（客戶確認）
3. 試匯入在 NAS 測試環境匯入，舊編號原樣保留，新開證書從新序列起算試匯入資料庫
4. 差異報告逐筆比對筆數、重複編號、缺圖、無法解析的日期與數值差異清單（需人工決定）
5. 正式切換凍結舊系統 → 正式匯入 → 舊系統改唯讀保留三個月切換紀錄、回滾點
舊證書匯入後可直接被「查詢／驗證」找到；公開驗證頁會標示「歷史資料，於 2026 年整併」。

NAS 部署

Synology Container Manager / QNAP Container Station
NAS（Synology / QNAP） ├─ Docker: cert-app 瀏覽器介面 + API（連接埠 8443） ├─ Docker: postgres 證書、範本、帳號、稽核紀錄 ├─ Volume: /volume1/cert │ ├─ uploads/ 物件照片、簽名檔 │ └─ backups/ 每日 pg_dump（保留 30 份） └─ NAS 快照 + Hyper Backup → 外接碟 / 異地 NAS 員工電腦、平板 ──(區網 HTTPS)──▶ NAS 客人手機掃 QR ──(對外驗證頁)──▶ 反向代理 → cert-app（唯讀 API）
硬體不綁定特定電腦；NAS 更換時將 Volume 與容器搬到新機即可
存取瀏覽器操作，不需安裝；平板可直接開立與拍照
備份資料庫每日轉存 + NAS 快照；還原演練納入驗收
公開驗證僅開放唯讀驗證 API 對外，後台限區網或 VPN
更新拉新版映像檔重啟即完成；資料庫遷移腳本隨版本附帶
